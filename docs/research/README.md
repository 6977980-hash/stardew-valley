# Research (Phase 0)

Phase 0 research was done before coding and lives in two shared documents:

- Keyword gap and SEO strategy report: https://claude.ai/code/artifact/1e534868-f2b9-41e9-a150-a7ed9a42634c
- Full site plan (7 phases, features, SEO/AEO/GEO, backlinks, AdSense): https://claude.ai/code/artifact/caa59059-d636-477b-b4ce-e45ff1b3a6b4

Key findings (October 2026):

- Several Stardew Valley tool sites registered in 2026 already show in top results for "best crops" and "crop profit calculator", so the authority bar is low.
- The clearest gaps are decision questions with no good tool in results: Keg vs Preserves Jar, Ancient Fruit vs Starfruit, greenhouse layout, fish pond profit, animal profit (Pig vs Cow), crafting totals.
- The official wiki owns entity keywords (villagers, items, fish lists); we link to it rather than compete.
