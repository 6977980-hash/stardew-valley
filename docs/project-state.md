**Known Issues:**
- Fruit trees and other artisan machines (Dehydrator, Fish Smoker…) are not in the data yet.
- Rice and Taro use unirrigated growth times.
- Powdermelon and Summer Squash: their own wiki pages split stages differently from the Crops page and
  the growth calendar (same total days). Two sources agree, so the data uses that split.
- Dinosaur Egg: wiki pages disagree on whether Rancher applies; marked needs-verification.
- Animal results take daily luck as 0 (an average day). Truffles count as regular quality.
- Winter has no Best Crops page (nothing grows outdoors); the Greenhouse page covers it.
- "Discourage search engines" must be unticked by the owner, then the sitemap is submitted in Google
  Search Console.
- The live Changelog page was created in Phase 1 and is never overwritten; new entries only reach
  fresh installs unless the page is edited.
- Ancient Seeds have no gold price, so their cost is not counted (shown on the page).
- LiteSpeed / Hostinger CDN: the plugin purges LiteSpeed on a version change, but the hPanel CDN may
  still need a manual purge after a deploy.

**Important Decisions:**
- Data is generated by importers from the wiki API, never hand-typed. Every crop needs two agreeing
  sources; every rule value needs its wiki sentence present, or the import fails.
- Engine is plain ES modules in `assets/js/engine/`, shared by browser and tests; no build step.
  Module URLs carry `?ver=` through an import map so CDN caches cannot mix versions.
- Speed-Gro uses the game algorithm with its float rounding (10-day crop with Speed-Gro: 8 days).
- Extra items of a multi-item harvest are regular quality (fertilizer affects only the first).
- Machine times use 1,600 minutes per day, as the wiki states; shown as approximate.
- Seeds without a gold price (Ancient Seeds, island trades) are not counted as free.
- Earlier: English site, "Stardew Tools" name, theme bundled in plugin, no SEO plugin, ads off until
  AdSense approval (apply after Phase 5).
- Tool short answers are built from the engine (`data/answers.json`) so page text never disagrees
  with the calculator; seasonal "best crop" answers only use seeds sold in shops.
- Greenhouse layouts: 6 Iridium Sprinklers (4 soil tiles) or 16 Quality (12 soil tiles), from the wiki.
- Machines needed = machine-days of work / days available, rounded up.
- What to Plant Today: only today's seeds bought now count against the budget; replanting is paid
  from sales. Machines work from the first harvest to the end of the season.
- Fish ponds: expected value = base chance x share x average quantity; Roe gets the 20% repeating
  extra-roe bonus (x1.25). Animals: Rancher on raw products only, Artisan on goods only.
- Best Crops pages are real, server-rendered ranked tables (one per season), not thin pages.
